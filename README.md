# 周报台 · 信息雷达周报编辑器

给**产品经理 / 运营**用的信息整理工作台：把一周散落的行业信息汇到一个条目池里，去重、按你自己定的规则打分，你来挑、你来写点评，最后导出 Markdown 或 HTML 周报。

**纯前端，打开即用，无账号、无服务器、无限额、完全免费。数据只存在你浏览器本地（IndexedDB），不会上传。**

## 适合谁 / 什么场景
- 每周要给团队发“行业动态 / 竞品 / 工具”周报的产品经理、运营、研究员
- 订阅了一堆 RSS、天天刷 Hacker News、GitHub，却没有一个地方把“值得写的几条”沉淀下来

## 解决什么问题
1. 信息源分散，同一件事多个源重复报道 → **链接规范化 + 标题相似度**去重
2. 不知道先看哪条 → **公开可调的打分规则**（关键词权重、来源权重、热度、时效），每条得分可展开看明细
3. 周报写作靠复制粘贴 → 从池里挑条目，**每条固定带原文链接 + 你自己写的点评栏**，一键导出
4. 担心数据被锁在某个平台 → 本地存储 + 备份 JSON 导出 / 导入

## 功能
- **信息源**：RSS / Atom 地址、Hacker News（官方 Algolia 接口：首页、近 7 天高分、Show HN、关键词搜索）、GitHub 近期新仓库（Search API）；添加前**先真实请求一次**，失败不会假装成功
- **粘贴导入**（给读不了的源）：粘贴链接 / 文本（支持“标题 | 链接”、Markdown 链接、上一行标题下一行链接）、粘贴 RSS/Atom XML、粘贴 OPML、也可直接选文件
- **条目池**：规范化去重、已读 / 星标、搜索、按来源 / 状态 / 时间筛选、按得分或时间排序、改标题、删除
- **打分规则**：`得分 = （来源分 + 热度分 + 关键词分）× 时效系数 + 星标加成`，参数全部可调，页面上写明公式
- **周报编辑**：挑选、上下排序、分组、点评栏（空白时导出标“待填写”并提示）、3 个内置模板 + 自定义模板（占位符）、预览、复制 Markdown、下载 `.md` / `.html`
- **备份**：导出 / 导入 JSON（合并或覆盖），超过 7 天未备份时提醒；清空数据需二次确认
- **可选 AI 摘要**：自己填 OpenAI 兼容接口的地址、模型、key；key 只存本机 localStorage，**不进备份、不进仓库**；摘要旁固定标注“AI 生成，需核对”并附原文链接；**不填 key 完整可用**

## 信息源跨域实测（2026-10-18，在本项目沙箱用真实浏览器 + curl 验证）
浏览器里的页面只能读取响应头带 `Access-Control-Allow-Origin`（CORS）的站点。**本工具不使用任何公共 CORS 代理**（会泄露你的订阅内容、也不稳定）。

| 状态 | 源 |
|---|---|
| ✅ 浏览器可直连（已在无头 Chrome 中真实抓取成功） | 少数派 sspai.com/feed、极客公园、雷峰网、Simon Willison、Wired、GitHub Blog、Google Blog、DEV Community、Hacker News（Algolia API）、GitHub Search API |
| ❌ 不支持（浏览器拦截，已实测） | 36氪、The Verge、人人都是产品经理、Product Talk、爱范儿 |
| ❌ 不支持（curl 实测无 CORS 头或被拒绝，未逐个在浏览器验证） | 阮一峰博客(403)、Product Hunt feed、Lenny’s Newsletter、Reddit(403)、TechCrunch（只允许自家域名）、SVPG、Nielsen Norman Group、Figma Blog、Stratechery 等 |
| ⚠️ GitHub trending | GitHub 没有官方 trending 接口，本工具用 Search API 查“近 N 天新建、按 star 排序”的仓库，是近似，不是 trending 页原榜单 |

上述可直连的源，也已用 `Origin: https://ysdtn.com`（线上域名）的请求头确认返回了允许该来源的 CORS 头。

这些结论来自 2026-10-18 的一次测试，站点日后可能变化；失败时页面会显示实际原因。不支持的源请用“粘贴导入”：在新标签打开订阅地址 → 全选复制 → 粘贴。

## 已知限制（如实）
- 数据在**单个浏览器**里：换设备 / 清浏览器数据会丢，请定期导出备份；无多设备同步
- 不能直连的源必须手动粘贴，没有后台定时抓取（纯前端无法后台运行）
- GitHub 搜索接口未登录时限流较严（约每分钟 10 次），连续抓取可能返回 403
- 标题相似度去重是字符二元组 Dice 相似度，可能把相似但不同的标题误合并（阈值可调，设 1 关闭；合并后条目上会显示“另有 N 个来源”）
- 没有发布时间的条目按抓取时间计入时效（得分明细里有标注）
- AI 摘要只用订阅源自带的摘要或你粘贴的片段；能否从网页直接调用你的接口取决于该接口是否允许跨域。我们**只用本地模拟接口验证了请求链路**，没有对任何真实模型接口做过验证
- Markdown 模板只影响 Markdown 导出；HTML 导出使用固定版式
- 未做离线 PWA / 同步 / 多人协作

## 本地运行 / 测试
直接打开 `index.html` 或用任意静态服务器。自测：`node tests/run.js`（需要 puppeteer-core 与 Chrome，抓取部分需联网）；最近一次结果见 `tests/result.txt`。
